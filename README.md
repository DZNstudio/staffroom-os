# StaffRoom OS

A playful operating-system shell where AI agents appear as characters in a staff room scene, with speech bubbles, a breakout room, a whiteboard and an "add agent" flow. Includes Files and Settings tabs.

## Run it
```bash
npm install
npm run dev
```
React, TypeScript, Vite.
